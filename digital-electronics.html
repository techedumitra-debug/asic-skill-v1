RELATED TOPIC · ANALOG DIGITAL

Analog and Digital Systems

An analog circuit processes signals that vary continuously in magnitude within a specified operating range. For example, the output voltage of a microphone preamplifier changes smoothly in response to variations in sound, taking on a continuous range of intermediate voltage levels.


In contrast, a digital circuit  processes and interprets signals using a finite set of discrete logic states, typically represented as **LOW (logic 0)** and **HIGH (logic 1)**. Although the actual voltage may vary within defined ranges, the circuit interprets these voltages as distinct logical values.

In summary, analog circuits represent information through continuously varying signals, whereas digital circuits represent information through discrete logic states.

Noise Immunity

Small electrical disturbances can affect signal accuracy because changes in voltage may alter the represented information.

Information Storage

Analog information can be stored, but maintaining its original accuracy over time may be challenging.

Digital information can be stored, copied, and retrieved reliably as binary data, provided valid logic levels are maintained.

Key distinction: “digital” does not mean that the electrical voltage changes instantaneously, nor that all digital signals must be sampled. The two-state interpretation is a logical abstraction.
1.1 · BENEFITS AND BOUNDARIES

Why use Digital Techniques?

Digital techniques are widely used in modern electronic systems because they provide reliable, flexible, and efficient ways to process, store, and transmit information. By representing information using discrete logic states, digital circuits can perform consistent operations even in the presence of small electrical disturbances.


Digital systems are also easier to design, modify, and expand using standardized logic components. Memory devices preserve information, programmable processors perform different tasks through software, and advanced integrated circuits combine millions or billions of transistors to implement complex functions within a compact chip.

Advantages of Digital Techniques

  • Reliability and Repeatability: Digital circuits use defined logic levels, allowing valid HIGH (1) and LOW (0) signals to be recognized consistently, even when small voltage variations occur.
  • Programmability: Digital processors can perform different operations by executing software instructions, allowing system functionality to be modified without redesigning the underlying hardware.
  • Data Storage: Flip-flops, registers, and memory devices store information in binary form, enabling reliable data retention, processing, and retrieval.
  • High Integration: Modern semiconductor technology allows millions or billions of transistors to be integrated onto a single chip, enabling compact, powerful, and cost-effective electronic systems.

Design Considerations and Limitations

  • Real-World Signals: Physical quantities such as temperature, pressure, sound, and light vary continuously. Digital systems often require sensors and signal-conversion circuits to process this information.
  • Signal Conversion: Analog-to-Digital Converters (ADCs) and Digital-to-Analog Converters (DACs) enable communication between analog and digital systems but introduce additional circuit complexity, conversion delays, and quantization effects.
  • Power Consumption and Speed: Digital circuits consume power during switching and may also dissipate leakage power. Higher operating frequencies and increased circuit complexity can raise power consumption and create timing challenges.
  • Limited Precision: Digital systems represent information using a finite number of bits. As a result, quantization and rounding may introduce errors, and information lost during conversion cannot be fully recovered.

A sensor measures a physical quantity, the ADC converts the measurement to a binary value, and the digital controller computes a response. A DAC or equivalent output stage drives the actuator.

Practical Example: Digitally Controlled Fan

Consider a digitally controlled cooling fan** that automatically adjusts its speed based on the surrounding temperature. A temperature sensor detects changes in temperature and produces a corresponding analog electrical signal. An **Analog-to-Digital Converter (ADC)  converts this signal into a digital value that can be processed by a microcontroller or digital control circuit.

The controller compares the measured temperature with a predefined threshold or desired temperature setting and determines the appropriate fan speed. Based on this decision, the controller generates a control signal that drives the fan through suitable power-control circuitry.

In many practical applications, **Pulse Width Modulation (PWM)** is used to regulate fan speed by adjusting the duty cycle of a digital control signal, eliminating the need for a separate Digital-to-Analog Converter (DAC).

This example demonstrates how analog sensing, digital processing, and electronic control work together to create an intelligent, automatic temperature-control system.

Key Takeaway:

Quick check · Is a digital thermometer entirely digital?

Not usually. A physical temperature signal must be sensed and interpreted; digital processing follows an analog sensing stage. That mix is the point of a hybrid system.

1.1 · MEMORY OR NO MEMORY

Combinational and sequential circuits

A combinational circuit computes an output from present inputs. An adder is an example: with the same bit inputs it gives the same sum and carry. A sequential circuit also uses stored state, so an identical current input can lead to a different result depending on what happened earlier.

Combinational

Y = f(inputs)

Logic gates, encoders, decoders, comparators and multiplexers compute values without intentional storage.

Sequential

Qnext = g(inputs, Qnow)

Registers, counters and finite-state machines keep state in latches or flip-flops.

Worked thought experiment · Why does a counter require memory?

To advance from 3 to 4, the circuit must know that its current count is 3. That existing count is stored state. A purely combinational circuit cannot track the number of earlier pulses without such a state input.

The system design view defines the product’s external behavior, data flow and performance targets before gates or transistors are selected. In a 4-bit accumulator, the goal is to add each incoming 4-bit value into a stored result.

What the block does

Interfaces and requirements

Device choices

Specify transistor sizes, voltage limits, output load, threshold models, noise margins and drive capability. Different standard-cell options trade area for speed and power.

1.2 · VOLTAGE LEVELS

HIGH, LOW and logic conventions

Binary values are abstract symbols, not necessarily exact voltages. In positive logic, the higher recognized voltage range denotes 1. In negative logic, the mapping is reversed.

The widths follow the actual voltage intervals: LOW spans 0.8 V, the indeterminate region spans 1.2 V, and HIGH spans 3.0 V. Changing logic convention reverses the binary meaning, not these physical input-voltage bands.

These bands are illustrative for a particular older logic family, not universal. Actual VIH, VIL, VOH and VOL limits vary with technology, supply and loading. An input in the unspecified middle region must not be assumed to resolve as a reliable 0 or 1.

RELATED TOPIC · LOGIC PULSES

Pulse waveforms, frequency and duty cycle

A pulse has transitions (edges), a high or low duration, and a repeating period when the waveform is periodic. In real hardware, edges take measurable time: rise time is often measured between 10% and 90% of the swing, and fall time between 90% and 10%. Pulse width is often defined at the 50% crossing points.

Explore · Clock generatorPeriod and duty cycle

Period T = 1 / f   ·   Duty cycle = tHIGH / T × 100%

Worked example · 20 MHz clock with 30% duty

The period is 1 / (20 × 10⁶) = 50 ns. HIGH time is 0.30 × 50 = 15 ns. LOW time is 35 ns. Frequency alone does not tell you the pulse duty cycle.

Arithmetic and comparison operations

Digital arithmetic is built from additions, shifts and logic. An adder combines operands and carry. A 4-to-2 encoder represents which one of four active-HIGH input lines is asserted using two binary output bits. This example assumes exactly one of D0–D3 is HIGH; it is not a priority encoder.

1.4.3 · DECODER

2-to-4 binary decoder

A 2-to-4 decoder reads input bits A1 and A0 and asserts one of four output lines. These outputs are active HIGH; exactly one Y output is 1 for each input combination when enable E is 1.

Explore · Choose the binary input2 inputs → 4 outputs

2-to-4 decoder truth table · active HIGH

Active-HIGH output equations

Y0 = E A̅1 A̅0   ·   Y1 = E A̅1 A0

Y2 = E A1 A̅0   ·   Y3 = E A1 A0

When E=0, all outputs are 0. When E=1 and A1A0=10, Y2 alone is HIGH. This is a decoder, not an encoder in reverse wiring—the physical gate network is different.

Related: code conversion

A code converter changes one coding convention into another. For example, BCD 0110 represents decimal six; Excess-3 for six is 1001.

1.4.4–1.4.5 · ROUTING DATA

Multiplexers and demultiplexers

A multiplexer (MUX) chooses one of several data sources and routes it to a common output according to a select code. A demultiplexer (DEMUX) routes one input value to one selected output, while other output lines stay inactive according to the design convention.

1.4.11 · INFORMATION MOVEMENT

Serial and parallel data transfer

Parallel transfer presents multiple bits during the same transfer interval over multiple signal lines. Serial transfer presents a sequence of bits over a smaller number of signal lines. The tradeoff includes pin count, layout complexity, clock recovery, protocol framing and link speed—not simply “parallel is always faster.”

Explore · Send one byteIllustrative physical bits

Serial transfer · 1 data line over eight time slots

Illustrative synchronous serial transfer with clock shown separately; asynchronous UART does not use a shared CLK wire.

Parallel transfer · 8 simultaneous data lines

Serial · one bit after another

Data appears in successive time slots on a single signal path (or a differential pair). Fewer data conductors simplify routing and cable connections. Protocols include UART, SPI, I²C and USB, although their framing and number of wires differ.

Watch: bit order, baud/bit rate, clock recovery, encoding and framing.

Parallel · many bits per beat

Multiple data wires transport bits at the same time. This may move an entire byte in one transfer beat, but requires more conductors and careful timing alignment. Examples include historical PATA/ATA, parallel SCSI and PCI, and on-chip parallel data buses.

Watch: setup/hold, skew, crosstalk and pin budget.

Engineering comparison: Parallel is not inherently faster: modern high-speed serial links can exceed traditional parallel interfaces through serialization, equalization and high symbol rates. The diagrams are conceptual, not protocol-level wiring requirements.
1.5 · FROM GATES TO CHIPS

Digital ICs and levels of integration

An integrated circuit combines many devices on a semiconductor substrate rather than wiring each transistor separately. Digital ICs can implement gates, decoders, arithmetic and memory. Historically, teaching materials classified chips by approximate equivalent-gate count using SSI, MSI, LSI, VLSI and ULSI.

Historical labelGate-count range in the provided chapterTypical example
SSIFewer than 12Basic gates
MSI12–99Counter, multiplexer
LSI100–9,999Small memory
VLSI10,000–99,999Larger integrated functions
ULSI100,000 or moreHistorical label for very large chips

The ranges above describe the chapter’s historical classification. They are not a meaningful contemporary limit on what engineers call VLSI; modern chips can contain billions of transistors.

Logic technology and implementation

TTL, ECL and IIL are classical bipolar logic families. MOS and especially CMOS use field-effect transistors. IC selection depends on supply, switching speed, power, noise tolerance, interface levels and packaging. Analog functions can also be integrated; the physical design constraints differ by application.

Microprocessors and digital computers

A microprocessor fetches instructions, decodes them, performs arithmetic and logical operations, and coordinates data movement. A complete computer also includes memory, inputs, outputs and control infrastructure. These blocks communicate through data, address and control paths.

1.9 · VERILOG & VHDL

Encoder and decoder HDL lab

Hardware description languages describe what hardware should do. This small lab defines a one-hot 4-to-2 encoder and matching 2-to-4 decoder. Both versions use explicit assignments so that the valid input mapping remains readable.

Input contract: for the encoder, exactly one of the four input bits must be HIGH. A valid output flags an invalid zero-hot or multi-hot pattern in the Verilog example.
Synthesizable Verilog 
module encoder4to2(input wire [3:0] d, output reg [1:0] code,
                   output reg valid);
  always @* begin
    code = 2'b00;
    valid = 1'b1;
    case (d)
      4'b0001: code = 2'b00;
      4'b0010: code = 2'b01;
      4'b0100: code = 2'b10;
      4'b1000: code = 2'b11;
      default: valid = 1'b0;
    endcase
  end
endmodule

module decoder2to4(input wire [1:0] code,
                   output wire [3:0] d);
  assign d = 4'b0001 << code;
endmodule
VHDL (IEEE std_logic_1164) 
library ieee;
use ieee.std_logic_1164.all;

entity encoder4to2 is
  port (d: in std_logic_vector(3 downto 0);
        code: out std_logic_vector(1 downto 0);
        valid: out std_logic);
end entity;
architecture rtl of encoder4to2 is
begin
  process(d) begin
    code <= "00"; valid <= '1';
    case d is
      when "0001" => code <= "00";
      when "0010" => code <= "01";
      when "0100" => code <= "10";
      when "1000" => code <= "11";
      when others => valid <= '0';
    end case;
  end process;
end architecture;

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;
entity decoder2to4 is
  port (code: in std_logic_vector(1 downto 0);
        d: out std_logic_vector(3 downto 0));
end entity;
architecture rtl of decoder2to4 is
begin
  d <= std_logic_vector(shift_left(to_unsigned(1, 4),
             to_integer(unsigned(code))));
end architecture;

Question · A periodic clock runs at 8 MHz with 25% duty cycle. What is its HIGH time?

Period = 125 ns; HIGH time = 0.25 × 125 ns = 31.25 ns.

Question · Why is a 4-to-2 encoder not a good arbitrary four-input logic compressor?

Two output bits can encode four mutually exclusive conditions. If several inputs are HIGH at once, multiple patterns conflict unless a priority and error policy is defined.
