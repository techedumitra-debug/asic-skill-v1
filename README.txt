# ASIC Skill — Website V1

A responsive starter website for ASIC-Skill.com.

## Files
- `index.html` — website structure/content
- `styles.css` — design and responsive styling
- `script.js` — mobile menu + course filters
- `logo.jpeg` — supplied ASIC Skill logo

## Run locally
1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click the file → **Open with Live Server**.
4. Your browser will open the website.
5. Edit `index.html` or `styles.css`, save, and refresh if necessary.
